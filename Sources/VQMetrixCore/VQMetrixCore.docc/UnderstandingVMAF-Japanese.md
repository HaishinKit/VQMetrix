# VMAFとスコアの読み方

圧縮後の映像を参照映像と比較し、目視確認と組み合わせて品質を判断します。

VMAF（Video Multimethod Assessment Fusion）は、Netflixが開発した学習ベースの映像品質指標です。
参照映像と、圧縮・復元した映像の対応するフレームを比較します。一般に点数が高いほど、そのモデルが想定する
視聴条件で参照映像に近いと推定されます。「画素が何％残ったか」「視聴者の何％が満足するか」という割合ではありません。

VQMetrix 1.0は **vmaf_v0.6.1** を使い、通常 **0〜100点** で表示します。
モデルや設定が変われば、想定する視聴条件やスコア範囲も変わります。同じ映像どうしでも必ず100点になるわけではありません。

## スコアの目安

以下は **VQMetrixで試行錯誤を始めるための目安で、Netflixの公式基準や見え方の保証ではありません**。
映像の内容、解像度、視聴距離、モデル、前処理によって解釈は変わります。

| スコア | 見方の目安 |
| --- | --- |
| 95〜100点 | 参照映像との類似度が非常に高い範囲です。ビットレートをさらに増やす価値があるか、目視でも確認します。「人間には見分けがつかない」という保証ではありません。 |
| 90〜95点未満 | 類似度が高く、画質目標の候補になる範囲です。配信サービス共通の合格基準ではありません。 |
| 80〜90点未満 | 用途によっては実用的な妥協点の候補です。細部や難しい場面では圧縮劣化が見えることがあります。 |
| 70〜80点未満 | 劣化が気にならないか、場面ごとの確認を重視したい範囲です。 |
| 70点未満 | 大きな違いがないか調べる目安です。圧縮劣化だけでなく、フレームのずれや色の解釈が正しいかも確認します。 |

「95点なら絶対に見分けがつかない」「90点あれば必ず十分」「70点未満はすべて使えない」とは判断しません。
スコアで候補を絞り、最後に目的の画面サイズと視聴条件で映像を確認してください。

## ライブ配信での出発点

VQMetrixで条件を探す際は、まず平均 **90点以上** を目指し、回線と端末に余裕があれば **90〜95点** を試す、という作業目安を提案します。
業界共通の合否基準ではありません。95点でもコマ落ち・発熱・遅延の増加が起きる設定より、90点前後で安定する設定を優先します。
低い点数になる場面と性能データを別々に確認してください。素材の再エンコードが速くても、ライブ配信全体が安定する保証にはなりません。

## 平均点だけで判断しない

1. **同じ参照フレーム・解像度・時刻・色の解釈・モデル**で条件を比較します。違う映像やモデルの点数をそのまま比較しません。
2. **グラフの落ち込みと低い点数の場面**も確認します。平均点が高くても、一瞬の目立つ劣化が隠れることがあります。
3. ビットレート、ファイルサイズ、エンコード負荷、表示する端末も考慮します。小さな文字、速い動き、ノイズ、静止画では傾向が変わります。
4. 圧縮前後のプレビューとレポートの評価済みフレーム数を確認します。一部だけを評価した結果は、そのフレームについての点数です。

参照映像そのものが低画質でも、それを忠実に再現できれば高い点数が出ることがあります。
VMAFは参照映像への忠実さを評価し、撮影時の本来の画質や映像の美しさを保証するものではありません。

## このアプリで測らないもの

macOSの計測は端末内で圧縮・復元します。アップロードした素材は保存済みの参照映像と比較映像を評価します。
音質、ネットワークでの配信状況、視聴者までの遅延、再バッファリングなど、視聴体験全体の評価は含みません。
評価できなかったフレームは別に記録します。高い平均点だけで「コマ落ちがない」とは判断しません。

既定のv0.6.1モデルにはHDTV・リビング視聴の想定があります。
モバイル端末で作った素材を評価しても、自動でスマートフォン向けモデルに切り替わるわけではありません。
